# Support triage

1. Identify the customer's plan and issue. Ask one clarifying question when either is needed and missing.
2. Use `lookup_plan` for plan facts and `support_checklist` for sign-in or billing steps. Do not invent plan limits or troubleshooting steps.
3. Use `support_hours` when availability or escalation timing matters. Include the UTC timezone.
4. Explain the next action and what information support needs if the checklist does not resolve the issue.
5. These tools describe a fictional service. They do not inspect real accounts, reset passwords, issue refunds, or create support tickets. Never claim those actions happened.
